VERSION: 2.1
LENGUAJE PRINCIPAL: Python 3.11.13
FRAMEWORK GUI: Tkinter
ENTORNO VIRTUAL: .venv311

DESCRIPCIÓN:
Sistema de reconocimiento y traducción de lengua de señas peruana (LSP) 
en tiempo real utilizando visión por computadora con MediaPipe y OpenCV.
Incluye historial de traducciones, síntesis de voz (TTS) y sistema de 
cooldown para evitar duplicados.

CARACTERÍSTICAS PRINCIPALES:
- Detección de manos en tiempo real con MediaPipe
- Clasificación de 10 señas peruanas base
- Historial de traducciones (máximo 100 entradas)
- Text-to-Speech con gTTS y pygame
- Sistema de cooldown anti-duplicados (configurable)
- Exportación de historial a TXT
- Interfaz gráfica moderna con Tkinter
- Estadísticas de sesión en tiempo real

================================================================================
  FLUJO DE DATOS Y ALGORITMOS
================================================================================

FLUJO PRINCIPAL DE DETECCIÓN:

1. CAPTURA DE VIDEO
   OpenCV captura frame de cámara (640x480)
   ↓

2. PROCESAMIENTO DE MEDIAPIPE
   MediaPipe detecta landmarks de mano (21 puntos x 3 coordenadas)
   ↓

3. EXTRACCIÓN DE CARACTERÍSTICAS
   SignFeatureExtractor convierte landmarks a 17 features
   ↓

4. CLASIFICACIÓN MULTI-MÉTRICA
   SignClassifier aplica 4 métricas:
   - Similitud coseno (30%)
   - Distancia euclidiana (20%)
   - Correlación de Pearson (20%)
   - Coincidencia de patrones (30%)
   ↓

5. SUAVIZADO TEMPORAL
   Historial de 5 frames, requiere 3 consistentes
   ↓

6. VALIDACIÓN DE CONFIANZA
   Si confianza > 0.6 → Seña válida
   ↓

7. SISTEMA DE COOLDOWN
   Si misma seña y tiempo < 2 segundos → Ignorar
   Si diferente seña o tiempo ≥ 2 segundos → Agregar
   ↓

8. ACTUALIZACIÓN DE HISTORIAL
   Agregar a translation_history (max 100)
   Actualizar UI
   ↓

9. TEXT-TO-SPEECH (OPCIONAL)
   gTTS genera MP3 → pygame reproduce audio

ALGORITMO DE COOLDOWN:

Función: add_to_history(sign_name, confidence, timestamp)
  
  current_time = obtener_tiempo_actual()
  
  # Verificar cooldown
  SI (last_sign_detected == sign_name) Y 
     ((current_time - last_sign_time) < sign_cooldown):
    RETORNAR  # Ignorar duplicado
  
  # Crear entrada de historial
  entry = {
    "id": generar_id(),
    "timestamp": timestamp,
    "sign": sign_name,
    "confidence": confidence,
    "datetime": formatear_fecha_hora(timestamp)
  }
  
  # Agregar al historial
  translation_history.agregar(entry)
  
  # Limitar tamaño
  SI len(translation_history) > 100:
    translation_history.eliminar_primero()
  
  # Actualizar estado
  last_sign_detected = sign_name
  last_sign_time = current_time
  
  # Actualizar UI
  update_history_display()

ALGORITMO DE TEXT-TO-SPEECH:

Función: speak_text(text)
  
  SI NO tts_available:
    RETORNAR
  
  # Crear archivo temporal
  temp_file = crear_archivo_temporal(".mp3")
  
  # Generar audio con gTTS
  tts = gTTS(text=text, lang='es')
  tts.save(temp_file)
  
  # Reproducir con pygame
  mixer.music.load(temp_file)
  mixer.music.play()
  
  # Esperar finalización
  MIENTRAS mixer.music.get_busy():
    esperar(100ms)
  
  # Limpiar archivo temporal
  eliminar(temp_file)

ALGORITMO DE CLASIFICACIÓN MULTI-MÉTRICA:

Función: classify_hand_landmarks(landmarks)
  
  # Extraer características
  features = feature_extractor.extract(landmarks)
  
  # Inicializar resultados
  best_sign = NULL
  best_confidence = 0.0
  
  # Comparar con cada seña del dataset
  PARA CADA seña EN dataset:
    
    # Calcular métricas
    cosine_score = cosine_similarity(features, seña.pattern)
    euclidean_score = euclidean_similarity(features, seña.pattern)
    correlation_score = correlation_similarity(features, seña.pattern)
    pattern_score = basic_pattern_match(features, seña.pattern)
    
    # Combinar con pesos
    combined_confidence = (
      cosine_score * 0.3 +
      euclidean_score * 0.2 +
      correlation_score * 0.2 +
      pattern_score * 0.3
    )
    
    # Actualizar mejor resultado
    SI combined_confidence > best_confidence:
      best_sign = seña
      best_confidence = combined_confidence
  
  # Suavizar con historial
  prediction = smooth_prediction(best_sign, best_confidence)
  
  # Validar umbral
  SI prediction.confidence > confidence_threshold:
    RETORNAR prediction
  SINO:
    RETORNAR NULL

  Parámetros: frame (numpy.ndarray): Frame de video BGR
  Retorno: processed_frame (numpy.ndarray)
  Descripción: Procesa frame con MediaPipe y clasifica señas

  Parámetros:
    - sign (str): Nombre de seña detectada

El programa usa threading de Python para operaciones no bloqueantes:

1. Detection Thread:

   - Propósito: Captura y procesamiento de video
   - Daemon: False (espera finalización limpia)

2. TTS Thread:
   - Función: speak_text()
   - Propósito: Síntesis y reproducción de audio
   - Daemon: True (puede interrumpirse)
